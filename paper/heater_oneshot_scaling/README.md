# Heater one-step scaling figure

This folder redraws `heater_oneshot_scaling.png`. The points are means over trials with `status=ok`. The error bars are the standard error of those trials. `d=8` uses the 8 trials that produced a posterior score.

```bash
python plot_heater_oneshot_scaling.py
```

`metrics.csv` is the input. `heater_oneshot_v4_brief.md` describes the screen and the discovery steps.
