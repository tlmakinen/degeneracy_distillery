Tape defaults

This file is the configuration for the four "default tape" buttons that appear in index_simple.html and index_tape.html. Both demo pages fetch this file at startup, parse the JSON below, and wire the buttons to the entries.

How to add or change a tape

  1. Drop your audio clip into ./audio/ (MP3 / OGG / WAV; short loop-friendly clips work best because the demo loops the deck).
  2. Edit the JSON in the <script type="application/json"> block below and bump the version query string in your blog's <iframe src> so browsers refetch.

Per-tape fields

  • label — button text shown in the deck (keep it short).
  • audioUrl — relative path to a CORS-friendly audio file (same-origin paths under ./audio/ Just Work). This is what plays through the demo's fader / equation chain.
  • spotifyUrl — optional. Renders a tiny green ♫ link next to the button that opens the full track on Spotify in a new tab. Set to null if you don't want one.

Tapes 1–2 attach to channel A (left). Tapes 3–4 attach to channel B (right). The order in the array is significant.
