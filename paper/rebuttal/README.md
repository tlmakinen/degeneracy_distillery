# Rebuttal reruns: three-step vs one-step

This folder rebuilds `comparison_table.md` from the per-trial records in
`records/`. It is self-contained: nothing here reads `/data103`.

```bash
python make_rebuttal_tables.py
```

`metrics.csv` is regenerated by that command, one row per
`(arm, experiment, seed)` — 40 three-step, 40 one-step, 20 config-variant.
Recovery is recomputed from the pre-registered criteria rather than read from
each record's `success` field, because the two arms' drivers set it by
different rules. Quartiles are `numpy.percentile` over all ten seeds; the build
asserts that this reproduces the published three-step table exactly and fails
if it does not.

`rebuttal_brief.md` describes both pipelines, the per-experiment setup and
criteria, and what is and is not comparable between the arms.
`PROVENANCE.md` records where the data came from and what was left on scratch.
